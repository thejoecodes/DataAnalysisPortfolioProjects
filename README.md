## 🧩 Project Summaries

| File | Summary | Tools |
|------|---------|-------|
| **Auto file sorter.ipynb** | Automates file organization by sorting documents into folders based on type or naming conventions. | Python (OS, shutil) |
| **CovidPortfolioProject.sql** | SQL queries analyzing COVID-19 data: infection rates, mortality, and vaccination trends. | SQL |
| **Customer Call List.xlsx** | Excel dataset cleaned and formatted for customer contact management. | Excel |
| **Data Cleaning in Pandas.ipynb** | Demonstrates cleaning messy datasets: handling nulls, duplicates, and formatting issues. | Python (Pandas) |
| **Excel Project.xlsx** | Business-focused Excel project with dashboards and pivot tables for insights. | Excel |
| **Formula Excel Project.xlsx** | Advanced Excel formulas (IF, INDEX, MATCH, etc.) applied to solve business problems. | Excel |
| **Jumia Web Scraping Project.ipynb** | Scrapes product data from Jumia to analyze pricing and availability trends. | Python (BeautifulSoup, Requests) |
| **Largest Companies in the US Data Scrapping.ipynb** | Extracts company data to study market capitalization and industry distribution. | Python |
| **NashvileHousingDataCleaning.sql** | SQL project cleaning housing data for real estate analysis. | SQL |
| **NashvilleHousingData.xlsx** | Raw dataset used in the housing data cleaning project. | Excel |
| **Working with API - Coinbase API.ipynb** | Pulls cryptocurrency data via API for trend analysis and visualization. | Python (API requests, JSON) |
| **XLOOKUP and VLOOKUP Excel.xlsx** | Demonstrates Excel lookup functions for efficient data retrieval. | Excel |
